Câu 1. Phân biệt position: relative và absolute

Position trong CSS dùng để xác định vị trí hiển thị của phần tử. Hai giá trị relative và absolute có cách hoạt động khác nhau.

Position: relative: Phần tử vẫn giữ vị trí trong luồng bố cục bình thường. Có thể dịch chuyển nó bằng top, right, bottom hoặc left. Khoảng trống ban đầu của phần tử vẫn được giữ lại. 


.box {
    position: relative;
    top: 10px;
    left: 10px;
}

Ví dụ: dịch chuyển nhẹ một biểu tượng hoặc tạo phần tử cha làm mốc định vị cho các phần tử con.

Position: absolute: Phần tử được đưa ra khỏi luồng bố cục bình thường và định vị theo tổ tiên gần nhất có position khác static. 


.product {
    position: relative;
}

.sale {
    position: absolute;
    top: 5px;
    right: 5px;
}

Ví dụ: đặt nhãn giảm giá ở góc ảnh sản phẩm. Khi thiết kế responsive, nên kết hợp Flexbox, Grid, đơn vị linh hoạt và media query để trang hiển thị tốt trên điện thoại và máy tính. Hosting không làm thay đổi ý nghĩa của hai thuộc tính CSS này.

Câu 2. Domain, Hosting và DNS

Domain là tên miền của website, ví dụ example.com. Hosting là nơi lưu trữ các tệp HTML, CSS, JavaScript và những tài nguyên của website.

Quy trình triển khai website gồm:

  1. Chọn và đăng ký tên miền tại nhà đăng ký.
  2. Chọn dịch vụ hosting phù hợp.
  3. Tải mã nguồn lên hosting hoặc kết nối với GitHub.
  4. Cấu hình DNS để tên miền trỏ đến dịch vụ hosting.
  5. Bật HTTPS và kiểm tra website trên nhiều thiết bị.

DNS có nhiệm vụ phân giải tên miền thành thông tin địa chỉ giúp trình duyệt tìm đến máy chủ phù hợp.

Hai công cụ triển khai website tĩnh phổ biến là GitHub Pages và Netlify. GitHub Pages có thể xuất bản website từ repository GitHub. Netlify hỗ trợ triển khai website tĩnh từ repository hoặc thư mục mã nguồn.

Rủi ro bảo mật gồm cấu hình DNS sai, không sử dụng HTTPS, để lộ API key trong JavaScript và sử dụng thư viện có lỗ hổng. Không nên lưu mật khẩu hoặc khóa bí mật trong mã nguồn phía trình duyệt.

Câu 3. So sánh var, let và const

Var có phạm vi hàm và được hoisting với giá trị ban đầu là undefined. Let và const có phạm vi khối lệnh; nếu truy cập trước dòng khai báo, chương trình sẽ phát sinh ReferenceError do Temporal Dead Zone.

Let cho phép gán lại giá trị. Const không cho phép gán lại biến và phải được khởi tạo khi khai báo, nhưng nội dung bên trong object hoặc array được khai báo bằng const vẫn có thể thay đổi. 


console.log(a);
var a = 10; // In ra undefined

// console.log(b);
// let b = 20; // ReferenceError nếu bỏ chú thích dòng trên

let age = 18;
age = 19; // Hợp lệ

const student = { name: "Dat" };
student.name = "An"; // Hợp lệ

Một lỗi thường gặp khi dùng var trong vòng lặp là các hàm callback có thể cùng tham chiếu một biến. Dùng let giúp mỗi vòng lặp có biến riêng. 


for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 0);
}
// Kết quả: 3, 3, 3

for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log(j), 0);
}
// Kết quả: 0, 1, 2

Có thể debug bằng Chrome DevTools: mở Console để xem lỗi, vào Sources đặt breakpoint, chạy từng bước và quan sát giá trị biến. Nên ưu tiên const, dùng let khi cần gán lại và hạn chế var.

Câu 4. Event Delegation

Event Delegation là kỹ thuật gắn một trình xử lý sự kiện lên phần tử cha thay vì gắn riêng lên từng phần tử con. Kỹ thuật này dựa vào cơ chế nổi bọt sự kiện (event bubbling). 


document.querySelector("#list").addEventListener("click", function(event) {
    const button = event.target.closest("button");

    if (!button || !this.contains(button)) {
        return;
    }

    alert("Bạn đã chọn: " + button.textContent);
});

Ví dụ: một danh sách sản phẩm có thể được thêm phần tử mới bằng JavaScript mà không cần gắn lại sự kiện cho từng nút. Cách làm này giúp giảm số lượng listener và dễ bảo trì. HTML tạo cấu trúc, CSS tạo giao diện và trạng thái tương tác, còn JavaScript xử lý sự kiện.
